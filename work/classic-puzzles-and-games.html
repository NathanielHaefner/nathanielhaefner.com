Classic Puzzles and Games

Classic Puzzles and Games

Dimensions

5.3in × 5.3in × .25in

7.5in × 5.5in × .625in

Medium

Baltic Birch, Acrylic, Glass, Cotton

Two Games to a Set

These classic games use plywood bases with colored glass marbles as pieces. Each set includes two different games played with the same set of marbles. The concept for this project was to move away from laser cut pieces to save on machine production time, while still maintaining a colorful end product.

Classic Brain Puzzles

The classic puzzles are single-player games. Each set includes a marble jump solitaire game as well as a color reversal game. Each set is distinguished by the pearl finish marbles as well as the geometric shape of the game boards—Square, Diamond, and Triangle.

Classic Strategy Games

The strategy games are two-player games that originated from the continent on the packaging. Each game is turn-based and similar in concept and difficulty to the familiar tic-tac-toe game. The marbles feature a matte finish and the colors are reminiscent of flags from that part of the world—Europe, Africa, and Asia.

Packaging

The packaging functions as the storage box as well as the instructions for playing each game. As with other Bright Beam products, the front sticker wraps onto the side of the box for better shelf labeling when seen from the side, but this sticker is extened to seal the box corner. This was especially important due to the weight added by the marbles to prevent movement durring shipping.

The box comes with a cotton drawstring bag to hold the marbles after the box has been opened.
